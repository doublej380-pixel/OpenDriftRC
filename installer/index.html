03

Connection recovery

If the board is not detected.

  1. 1

    Keep the USB cable connected and hold the BOOT button.

  2. 2

    While holding BOOT, press and release RESET.

  3. 3

    Release BOOT, click Install again, and select the newly detected serial port.

This is the download-mode sequence documented by Waveshare for both supported boards.

After installation

Reconnect. Calibrate. Create a profile. Go drive.
